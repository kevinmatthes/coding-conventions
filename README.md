# `coding-conventions`

Check the coding conventions of a repository with small, neutral,
parameterised rules.

`coding-conventions` is a library of small rules, each checking one property
of a file:  how many columns a line may hold, how many spaces follow a full
stop, which spellings are rejected.  A rule names the property it checks and
nothing else, so the conventions of a project are the rules it calls, with the
parameters it chooses.

> **Made with Anthropic Claude.**  The project scaffold and parts of the
> implementation and the documentation are written by Claude, working to the
> direction and review of the author, who designs the rules by hand and with
> whom every design decision rests.  Each commit names the model in a
> `Co-Authored-By` trailer, so the record is per change rather than only
> here.

## Status

At the very beginning.  The repository holds the project scaffold:  manifest,
licence, continuous integration and the conventions harness of this very
repository.  The rules themselves are designed by hand, one at a time, and
none is published yet.
